# 통화 합계와 해외주식 예상 세금

## 통화 보기

등록 주식 합계는 원화 전체 환산액 + 통화별 원금액을 병기한다.
외화가 없는 합계는 원화만 표시한다. 통화별 합계에 서로 다른 통화를 더하지 않는다.
시세가 없는 종목은 평가·손익에서 제외하고 일부 표시, 매입가에는 포함한다.
환율 미확인 시 해당 원화 환산은 보류하되 USD/JPY 원금액은 유지한다.
표의 원화 보기 체크는 종목 행에만 적용되며 합계의 병기 금액은 항상 유지된다.

## 예상 세금의 범위

- 규칙 확인일 2026-09-18, **2026년 귀속 일반 미국·일본 주식**만 지원한다. 이후 귀속연도에 자동 적용하지 않는다.
- 한국 과세대상 거주자이고 일반 세율이 적용된다는 사용자 확인 아래 계산한다. 거주기간·귀국 이력 등 과세대상 판정은 자동으로 하지 않는다.
- 사용자는 두 나라 각각 **모든 증권사·직접/자동 실계좌**의 세금용 원화 연간 실현손익을 입력한다. 미국·일본을 구분하되 공제는 합쳐서 한 번만 적용한다.
- 상단 계좌 필터와 독립적이며 모의계좌, 국내주식, 배당, 다른 국가 주식, PTP 등 특수상품은 포함하지 않는다. 국내주식이 항상 비과세라는 의미가 아니다.
- 다른 과세대상 주식, RIA 등 공제·감면이나 외국납부세액이 있는 경우 이 계산기는 적용하지 않는다.
- 보유잔고의 평균단가·현재 환율로 계산한 평가손익과 자동매매 누적성과는 세금용 원가/연간 실현손익이 아니므로 자동 입력하지 않는다. 증권사 양도소득세 자료를 사용한다.
- 빈칸, 소수, 비정상 숫자는 0원으로 간주하지 않는다. 입력은 원 단위 정수, 항목별 절댓값 1조 원 이하. 손실은 음수, 실제 거래 없음은 명시적 0.

일반 예상 세금: `max(0, 미국 실현손익 + 일본 실현손익 - 2,500,000) × 22%`.
국세 20%와 지방세 2%를 나누어 원 미만을 버린 참고 추정치이며, 신고·납부세액 확정/신고서 생성 기능이 아니다.
예상 세후 실현손익은 입력 실현손익 합계에서 해당 예상 세금을 차감한다. 손실이라고 세금을 음수로 만들지 않는다.

### 지금 매도한다면

웹에 등록된 모든 미국·일본 실계좌 보유분만 현재 시세·환율로 평가한다.
시세·환율/보유 내역이 미확인이면 결과를 보류한다. 실제 체결·주문은 실행하지 않는다.
사용자는 그 수량에 대응하는 **세금용 취득가액 + 매수비용**, 별도 예상 매도비용을 원화로 입력한다.
기존 연간 예상 세금과 가정 매도 후 예상 세금의 차이만 차감하므로 연 250만 원 공제를 중복 사용하지 않는다.
손실 실현으로 생기는 음수 세금 증감은 연간 세금 감소이며 즉시 환급을 뜻하지 않는다.
미등록 보유분, 중복 등록, 실제 결제일 환율·체결가·비용 차이는 결과에 영향을 준다.

입력은 컴포넌트 메모리에서만 계산하며 서버·브라우저 저장소에 저장하지 않는다.
새로고침/로그아웃으로 초기화되며 백업 범위에도 포함되지 않는다.

## 입출금 조정 수익률

세후 매매손익과 별개다. Stock-Trading의 기존 `importCashFlows`/`!account import` 경로는 계좌·기간 증빙을 검증하고 일별 Modified Dietz 수익률을 계산할 수 있다.
현재 증권사 거래 조회는 매매·비용 대조용으로, 전체 외부 입출금을 누락 없이 수집했다는 증빙을 대신하지 않는다.
증권사 명세서의 계좌·기간·통화·시각·금액과 외부 주식 입출고 등의 반영 여부를 확인한 뒤 가져와야 한다.
동일 평가 범위 내부 매매·환전은 외부 입출금으로 중복 계산하지 않는다. 전체 기간 거래 없음도 명세서 확인이 필요하다.
명세서 반영 후 자산 이력을 다시 전송해야 웹에서 계산 결과를 볼 수 있다. 이번 변경은 증빙을 임의 생성하거나 운영 명세서를 수정하지 않는다.
연동 자산 이력은 현재 KRW/USD 범위만 지원하며 일본 보유종목 표시 지원과 동일하지 않다.
